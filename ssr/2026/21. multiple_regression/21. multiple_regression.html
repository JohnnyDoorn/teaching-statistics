Multiple regression

\(\LARGE{\text{outcome} = \text{model prediction} + \text{error}}\)

In statistics, linear regression is a linear approach for modeling the relationship between a scalar dependent variable y and one or more explanatory variables denoted X.

\(\LARGE{Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \dotso + \beta_n X_{ni} + \epsilon_i}\)

In linear regression, the relationships are modeled using linear predictor functions whose unknown model parameters \(\beta\)’s are estimated from the data.

Source: wikipedia

Assumptions

A selection from Field (8.3 Bias in linear models):

For simple regression

  • Sensitivity
  • Homoscedasticity
    • See here for further illustration
  • Linearity
  • Normality

Additionally, for multiple regression

  • Multicollinearity (Section 8.9)

Multicollinearity

To adhere to the multicollinearity assumption, there must not be a too high linear relation between the predictor variables.

This can be assessed through:

  • Correlations
  • Matrix scatterplot
  • Collinearity diagnostics
    • VIF: max < 10, mean not substantially > 1
    • Tolerance > 0.2 -> good
    • Tolerance = \(\frac{1}{VIF}\)

Linearity

For the linearity assumption to hold, the predictors must have a linear relation to the outcome variable.

This can be checked through:

  • Correlations
  • Matrix scatterplot with predictors and outcome variable

Robust alternative: bootstrap

  • Assumptions in doubt? Confidence intervals and \(p\)-values may be off
  • Bootstrap the coefficients (Section 8.12)
    • Statistics → Coefficients → From 5000 bootstraps
    • Output: Bootstrap Coefficients table
  • More robust methods (e.g., winsorizing, Section 6.10.7)
    • Robust Statistics module (WRS2)
    • Not exam material

Explained variance

The explained variance is the deviation of the estimated model outcome compared to the grand mean.

To get a percentage of explained variance, it must be compared to the total variance. In terms of squares:

\(\frac{{SS}_{model}}{{SS}_{total}}\)

We also call this: \(r^2\) or \(R^2\).

Why?

r <- cor(sales, predicted.sales)

Hierarchical regression

Isolating individual contributions

  • What does a predictor add on top of the others?
  • Enter predictors in steps, known ones first (past research)
  • \(R^2\) change is the extra variance the new predictors explain
  • \(F\) change tests whether that increase is more than chance

\[F_{change} = \frac{(N - k_{new} - 1)\, R^2_{change}}{k_{change}\, (1 - R^2_{new})}\]

  • Album sales (Section 8.10), adding airplay and image to adverts
    • \(R^2\) goes from 0.335 to 0.665, \(F\)(2, 196) = 96.447, \(p\) < .001

Checking the assumptions

Where to check each assumption in JASP (final model)

Assumption In JASP Looks fine when
Multicollinearity Statistics → Coefficients → Tolerance and VIF all VIFs below 10, average close to 1
Linearity, equal variances Plots → Residuals vs. predicted a random cloud around 0
Normality of the residuals Plots → Q-Q plot standardized residuals → Confidence interval points close to the line, mostly within the band
Outliers, influential cases Statistics → Residuals → Casewise diagnostics about 5% of std. residuals beyond \(\pm 2\) at most, Cook’s distance below 1
